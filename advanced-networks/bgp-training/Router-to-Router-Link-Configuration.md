# Router-to-Router Link Configuration

وقتی می‌خواهیم دو روتر را مستقیماً به هم وصل کنیم، به دو IP قابل استفاده نیاز داریم؛ بنابراین `/30` انتخاب مناسبی است.

مثلاً شبکه زیر را در نظر بگیر:

`10.0.0.0/30`

این شبکه ۴ آدرس دارد:

| IP         | کاربرد            |
| ---------- | ----------------- |
| `10.0.0.0` | Network Address   |
| `10.0.0.1` | قابل اختصاص به R1 |
| `10.0.0.2` | قابل اختصاص به R2 |
| `10.0.0.3` | Broadcast Address |

**R1**

# **10.0.0.1**

10.0.0.0/30

**R2**

# **10.0.0.2**

### **پس قانونش اینه:**

- IP اول: آدرس شبکه است و به روتر اختصاص نمی‌دهیم.
- IP دوم: به اینترفیس روتر اول می‌دهیم.
- IP سوم: به اینترفیس روتر دوم می‌دهیم.
- IP چهارم: Broadcast است و به روتر اختصاص نمی‌دهیم.

Subnet Mask هم برابر است با:

```
255.255.255.252
```
